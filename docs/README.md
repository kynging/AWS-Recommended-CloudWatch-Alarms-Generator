## Documentation Overview

### Architecture Documentation

Learn about the system design and how components interact:
- High-level architecture diagram
- Component details (Lambda functions, IAM roles, S3 buckets, etc.)
- Execution flow and alarm generation logic
- Scalability and high availability considerations
- Security architecture
- Cost optimization strategies

**Target Audience**: Architects, DevOps engineers, and developers who need to understand how the system works.

### Deployment Guide

Step-by-step instructions for deploying and configuring the application:
- Prerequisites and requirements
- Installation methods (SAR, SAM CLI, CloudFormation)
- Configuration parameters
- Environment-specific deployments
- Usage examples and testing
- Troubleshooting common issues

**Target Audience**: Platform engineers, DevOps teams, and system administrators responsible for deployment.

### Operations Guide

Daily operations and maintenance procedures:
- Health checks and monitoring
- Key metrics and dashboards
- Maintenance tasks (weekly, monthly)
- Backup and restore procedures
- Incident response playbooks
- Performance tuning
- Upgrade procedures

**Target Audience**: Operations teams, SREs, and on-call engineers managing the running system.
